# 🐙 OctoCat-Code

> *Le Grand Kernel Crash a frappé GitHubia. Les structures de données s'effondrent, les fichiers sources se corrompent, et des **Glitches** rôdent entre les Portails à Code.*

Tu incarnes l'**OctoCat**, mi-chat mi-pieuvre, dernier gardien du dépôt originel. Pour restaurer les fichiers sources, tu dois franchir les Portails à Code — et chaque portail ne s'ouvre qu'avec **du vrai code**, écrit de ta main.

**Ici, le site est le jeu** : lis le cours, observe la scène, écris ta solution, clique sur **⚡ Compiler**, et regarde l'OctoCat agir.

## Les trois zones

| Zone | Difficulté | Ce que tu apprends |
|------|-----------|--------------------|
| **1** | Facile | La logique pure, en pseudo-code (variables, conditions) |
| **2** | Moyen | HTML/CSS ou JavaScript pour agir sur l'environnement |
| **3** | Difficile | Python ou JavaScript (Node) : boucles, fonctions, tableaux |
