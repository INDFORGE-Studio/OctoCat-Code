## La notion : la variable

Une **variable** est une boîte étiquetée qui garde une valeur. On lui donne un nom, puis on lui **assigne** une valeur avec le signe `=`.

=== "Pseudo-code"

    ```text
    v_vie = 3
    ```

=== "Python"

    ```python
    v_vie = 3
    ```

=== "JavaScript"

    ```javascript
    let v_vie = 3;
    ```

!!! tip "À retenir"
    - `=` **donne** une valeur (assignation) ; `==` **compare** deux valeurs.
    - Le nom d'une variable respecte la casse : `v_speed` et `V_Speed` sont deux boîtes différentes.

## L'énigme

Le Glitch ne recule que devant un OctoCat lancé à pleine vitesse. Déclare la variable **`v_speed`** et donne-lui la valeur **`200`**.
